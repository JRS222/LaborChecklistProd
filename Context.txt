What went wrong

Your dumps pinpoint the exact bug. Reading them in order:

1. gstrTableSQL_raw is truncated mid-expression

```
...'\x3Ca href=\"javascript:goToIDS(''' || machine.Ids_Name ||   ''',' || '''GENMP'',' || machine.ndss_mach_id || ',' ||  machine.site_id || ',' || machine.machine_id || ')
```

Notice it ends on a ) — no closing quote, no closing paren, no FROM, no WHERE, no ORDER BY. The regex was 'gstrTableSQL\s*=\s*([\s\S]*?);' — non-greedy, stopping at the first ;. But the SQL contains );\">source\x3C/a>') inside string literals. The regex matched the first ; it saw, inside the SQL, and stopped there.

That truncated SQL is what got POSTed to GUI_Report_CSV.asp, which is why you got Invalid Data Source! — the SQL was not a complete statement.

2. The CSV endpoint needs all five gstrTable* variables

The debug HTML includes the exact JavaScript the browser runs:

```javascript
function generateTableCSV() {
    document.getElementById("tabCsvGroup").value   = gstrTableHeaderGroup;
    document.getElementById("tabCsvHeader").value  = gstrTableHeader;
    document.getElementById("tabCsvColumns").value = gstrTableColumns;
    document.getElementById("tabCsvSource").value  = gstrTableSource;
    document.getElementById("tabCsvSQL").value     = gstrTableSQL;
    document.getElementById("frmTableCSV").submit();
}
```

The browser sends all five. Our original code sent tabCsvGroup = " " (single space — wrong; the browser sends the full quoted header list) and hardcoded tabCsvColumns / tabCsvHeader. We should just extract and relay all five.

3. Status=Active was wrong

The HTML form options are:

```html
<OPTION VALUE="Y">Active</OPTION>
<OPTION VALUE="N">Inactive</OPTION>
<OPTION VALUE="ALL">ALL</OPTION>
```

Sending Status=Active made the server produce AND machine.active_ind = 'Active', which matches nothing (values are 'Y'/'N'). Should be Status=Y.

4. The -replace '<a\s+[^>]*>source</a>', '' line was unnecessary

Column indices 19,11,1,9,2,15,3,8,12,24,13,25,17,18,5,6,10,16,20 don't include 21 (the source_link column). The anchors never make it into the CSV, so stripping is a no-op at best and could corrupt real data at worst. Removed.

Replacement Save-MachineMappingCsv function

Paste this over the old one in Get-WebEorCsv.ps1. Everything else is unchanged.

```powershell
# ---------------------------------------------------------------------------
# WebEOR — machine mapping CSV
#   Relays the browser's exact request: extract the five gstrTable* JS
#   variables from the viewer page and POST them verbatim to the CSV endpoint.
#   Proper JS string-literal parsing keeps the full SQL when it contains
#   embedded ';' inside DECODE string fragments.
# ---------------------------------------------------------------------------
function Save-MachineMappingCsv {
    param(
        [Parameter(Mandatory)] $Session,
        [Parameter(Mandatory)] [int]    $SiteId,
        [Parameter(Mandatory)] [string] $OutFile
    )

    Write-DlLog "  [mapping] GET viewer (site $SiteId)..." -Level Info

    # Same form fields the browser submits. Status uses the FORM VALUE ('Y'),
    # not the display label ('Active').
    $viewerFields = [ordered]@{
        Help_Loc      = "/WebHelp/WebEOR_Help.htm#Mapping_Machine_Information.htm"
        MACHTYPE      = "ALL"
        SITEID        = "$SiteId"
        Status        = "Y"
        cmdRefresh    = "Refresh Table"
        SF            = ""
        ST            = ""
        ARG1          = ""
        ARG2          = ""
        MultiSort     = "A_SITE_NAME,A_MACHINE,A_MNO"
        FieldNames    = "GLOBAL_MACHINE_ID,SITE_NAME,MACHINE,EQUIPMENT_CODE,MNO,MAX_BIN_NBR,EOR_SW_VER,MODS_MACH_ID,NDSS_MACH_ID,MPE_ID,IOS_MACH_ID,LIFT_UNIT_NBR,FORMAT_EFFECTIVE_START_DATE,FORMAT_EFFECTIVE_END_DATE,SERIAL_NO,CAPITAL_ID_NO,D_ENABLED,FORMAT_DATETIME_DTM,SOURCE_LINK"
        FieldLabels   = "Global ID,Site Name,Machine Type,Model,MNO,Max Bin#,S/W Ver,MODS,NDSS,MPE ID,IOS,Lift Unit,Eff Start Date,Eff End Date,Serial,Capital ID,Status,Changed Date,Source"
        RecordsListed = "0"
    }
    $qs = ($viewerFields.GetEnumerator() | ForEach-Object {
        "$([uri]::EscapeDataString($_.Key))=$([uri]::EscapeDataString([string]$_.Value))"
    }) -join '&'

    try {
        $viewer = Invoke-WebRequest -Uri "$($script:Base)/mapping/GUI_MachineInfo_Viewer.asp?$qs" `
            -WebSession $Session -UseDefaultCredentials -UseBasicParsing `
            -Headers @{ Referer = "$($script:Base)/mapping/GUI_MachineInfo_Viewer.asp" } `
            -TimeoutSec 900
    } catch {
        throw "Mapping viewer GET failed: $($_.Exception.Message)"
    }

    Write-DlLog "  [mapping] viewer returned $($viewer.RawContentLength) bytes" -Level Info
    Write-MappingDebugDump -Name 'viewer' -Content $viewer.Content -Extension 'html'

    # -------------------------------------------------------------------
    # Extract a `var NAME = "…";` JS string literal in full.
    #
    # The character class `(?:[^"\\]|\\.)` matches either a char that is
    # NOT a bare quote or backslash, OR a backslash-escaped char. That
    # correctly consumes `\x3C`, `\"`, `\\`, and — critically — a raw
    # `;` inside the SQL (like `');">`), instead of truncating at it.
    # -------------------------------------------------------------------
    function Extract-JsVar {
        param([string]$Html, [string]$Name)
        $pattern = 'var\s+' + [regex]::Escape($Name) + '\s*=\s*"((?:[^"\\]|\\.)*)"\s*;'
        $m = [regex]::Match($Html, $pattern)
        if (-not $m.Success) { return $null }
        return $m.Groups[1].Value
    }

    # Decode JS string-literal escapes to the actual string value the browser
    # would compute. Handles \xHH, \uHHHH, \", \', \n, \r, \t, \\.
    function Decode-JsString {
        param([string]$Raw)
        if ($null -eq $Raw) { return $null }
        $sentinel = [string][char]0x0001
        $s = $Raw
        # 1) Protect \\ so \xHH decodes don't misfire on escaped backslashes
        $s = $s -replace '\\\\', $sentinel
        # 2) \xHH → char
        $s = [regex]::Replace($s, '\\x([0-9A-Fa-f]{2})', {
            param($m) [string][char][Convert]::ToInt32($m.Groups[1].Value, 16)
        })
        # 3) \uHHHH → char
        $s = [regex]::Replace($s, '\\u([0-9A-Fa-f]{4})', {
            param($m) [string][char][Convert]::ToInt32($m.Groups[1].Value, 16)
        })
        # 4) Simple escapes
        $s = $s -replace '\\"',  '"'
        $s = $s -replace "\\'",  "'"
        $s = $s -replace '\\n',  "`n"
        $s = $s -replace '\\r',  "`r"
        $s = $s -replace '\\t',  "`t"
        # 5) Restore \\
        $s = $s.Replace($sentinel, '\')
        return $s
    }

    $rawSql    = Extract-JsVar -Html $viewer.Content -Name 'gstrTableSQL'
    $rawHeader = Extract-JsVar -Html $viewer.Content -Name 'gstrTableHeader'
    $rawGroup  = Extract-JsVar -Html $viewer.Content -Name 'gstrTableHeaderGroup'
    $rawCols   = Extract-JsVar -Html $viewer.Content -Name 'gstrTableColumns'
    $rawSource = Extract-JsVar -Html $viewer.Content -Name 'gstrTableSource'

    if ($null -eq $rawSql) {
        Write-MappingDebugDump -Name 'viewer_no_sql' -Content $viewer.Content -Extension 'html'
        throw "Mapping viewer missing gstrTableSQL (bytes=$($viewer.RawContentLength))"
    }

    Write-DlLog "  [mapping] raw gstrTableSQL: $($rawSql.Length) chars" -Level Info
    Write-MappingDebugDump -Name 'gstrTableSQL_raw' -Content $rawSql

    $decSql     = Decode-JsString $rawSql
    $decHeader  = Decode-JsString $rawHeader
    $decGroup   = Decode-JsString $rawGroup
    $decCols    = Decode-JsString $rawCols
    $decSource  = Decode-JsString $rawSource

    if ($null -eq $decHeader) { throw "Missing gstrTableHeader in mapping viewer" }
    if ($null -eq $decCols)   { throw "Missing gstrTableColumns in mapping viewer" }
    if ($null -eq $decSource) { $decSource = "CLIENT" }
    if ($null -eq $decGroup)  { $decGroup  = $decHeader }   # fall back to header

    Write-DlLog "  [mapping] decoded SQL: $($decSql.Length) chars" -Level Info
    Write-MappingDebugDump -Name 'mappingSql_decoded' -Content $decSql

    # Sanity — a well-formed SQL must have SELECT and FROM, and must contain
    # the site id we filtered by. Any failure here means the extractor missed.
    if ($decSql -notmatch '\bSELECT\b' -or $decSql -notmatch '\bFROM\b' -or $decSql -notmatch '\bORDER BY\b') {
        Write-MappingDebugDump -Name 'mappingSql_suspicious' -Content $decSql
        throw "Decoded SQL is not a complete SELECT (missing SELECT/FROM/ORDER BY) — extractor may have truncated"
    }
    if ($decSql -notmatch [regex]::Escape("$SiteId")) {
        Write-DlLog "  WARN decoded SQL missing site id $SiteId" -Level Warn
    }

    Write-DlLog "  [mapping] SQL sanity check passed" -Level Success

    # -------------------------------------------------------------------
    # Relay exactly what the browser relays.
    # -------------------------------------------------------------------
    $body = @{
        tabCsvGroup   = $decGroup
        tabCsvHeader  = $decHeader
        tabCsvColumns = $decCols
        tabCsvSource  = $decSource
        tabCsvSQL     = $decSql
    }

    $tmp = "$OutFile.tmp"
    Remove-Item $tmp -Force -ErrorAction SilentlyContinue

    Write-DlLog "  [mapping] csv POST (cols=$decCols)" -Level Info
    try {
        $null = Invoke-WebRequest -Uri "$($script:Base)/ReportPage/GUI_Report_CSV.asp" `
            -Method POST -Body $body -WebSession $Session `
            -UseDefaultCredentials -UseBasicParsing `
            -Headers @{ Origin = $script:Base; Referer = "$($script:Base)/mapping/GUI_MachineInfo_Viewer.asp" } `
            -OutFile $tmp -TimeoutSec 900
    } catch {
        $partial = if (Test-Path $tmp) { (Get-Item $tmp).Length } else { 0 }
        if ((Test-Path $tmp) -and $script:DebugMapping) {
            $rawDump = Get-Content $tmp -Raw -ErrorAction SilentlyContinue
            Write-MappingDebugDump -Name 'csv_partial_response' -Content $rawDump -Extension 'txt'
        }
        Remove-Item $tmp -Force -ErrorAction SilentlyContinue
        throw "Mapping CSV POST failed after $partial bytes: $($_.Exception.Message)"
    }

    if (-not (Test-Path $tmp)) { throw "Mapping CSV POST produced no file" }
    $size = (Get-Item $tmp).Length

    if ($script:DebugMapping) {
        $rawDump = Get-Content $tmp -Raw -ErrorAction SilentlyContinue
        Write-MappingDebugDump -Name 'csv_response' -Content $rawDump -Extension 'csv'
    }

    if ($size -lt 100) {
        $head = Get-Content $tmp -Raw -ErrorAction SilentlyContinue
        Remove-Item $tmp -Force -ErrorAction SilentlyContinue
        throw "Mapping CSV response too small ($size bytes). Content: $head"
    }

    $fs = [System.IO.File]::OpenRead($tmp)
    try {
        $headBytes = New-Object byte[] ([Math]::Min(300, $size))
        $null = $fs.Read($headBytes, 0, $headBytes.Length)
        $headText = [System.Text.Encoding]::ASCII.GetString($headBytes)
    } finally { $fs.Close() }

    if ($headText -match '<HTML|Unrecongized|Unrecognized|Invalid Data Source|Data Source') {
        Remove-Item $tmp -Force -ErrorAction SilentlyContinue
        throw "Mapping CSV endpoint returned HTML ($size bytes): $($headText.Substring(0,[Math]::Min(160,$headText.Length)))"
    }
    if ($headText -notmatch 'Global ID|Site Name|Machine Type') {
        Remove-Item $tmp -Force -ErrorAction SilentlyContinue
        throw "Mapping CSV header mismatch ($size bytes). Head: $($headText.Substring(0,[Math]::Min(200,$headText.Length)))"
    }

    if (Test-Path $OutFile) { Remove-Item $OutFile -Force }
    Move-Item $tmp $OutFile
    Write-DlLog "  [mapping] OK $size bytes -> $OutFile" -Level Success
    return (Get-Item $OutFile)
}
```
