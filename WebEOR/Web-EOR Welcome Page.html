 Welcome to WebEOR 1.1.71.07

WebEOR provides the capability to reproduce, archive or summarize any or all information captured during an MPE run and to present this information in report-form. WebEOR reports can be used to measure machine performance, to track machine location, and for planning or trend purposes. WebEOR offers the user a number of standard reports, including reports for operations, maintenance, and machine configuration data, and has the capability to generate custom reports that are created by the user.
